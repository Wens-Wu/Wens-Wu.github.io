### 目标

在 Ubuntu 多用户服务器上，为所有使用 Bash 的用户启用类似 zsh / fish 的历史命令灰色自动补全效果：

- 用户输入命令前几个字符后，自动显示历史命令剩余部分；
- 自动建议以灰色或较暗颜色显示；
- 可使用 `→`、`End`、`Ctrl+F` 等按键接受建议；
- 每个用户只使用自己的命令历史；
- 不共享不同用户之间的 Bash 历史；
- ble.sh 全局安装一次，所有用户共同使用。

以如下公共安装路径为例：

```
/opt/share/blesh
```

适用于 Ubuntu 24.04 等常见 Linux 服务器环境。

### 原理

Bash 本身支持历史记录，但默认不会像 zsh-autosuggestions 一样在当前输入行后面实时显示灰色历史建议。

这里使用：

```
ble.sh
```

为 Bash 增加：

- 历史命令自动建议；
- 灰色 inline autosuggestion；
- Bash 行编辑增强；
- 语法高亮等功能。

整体结构如下：

```
所有用户
   │
   ├── /home/user1/.bash_history
   ├── /home/user2/.bash_history
   └── /home/user3/.bash_history
            │
            ▼
       Bash History
            │
            ▼
        ble.sh
            │
            ▼
   灰色历史命令自动提示
```

ble.sh 本身统一安装在：

```
/opt/share/blesh
```

但每个用户仍使用自己 HOME 目录中的：

```
~/.bash_history
```

因此不会发生不同用户之间互相读取历史命令的问题。

### 安装ble.sh

进入公共软件目录：

```
cd /opt/share
```

克隆 ble.sh：

```
sudo git clone --recursive --depth 1 https://github.com/akinomyoga/ble.sh.git blesh
```

进入源码目录：

```
cd /opt/share/blesh
```

编译：

```
sudo make
```

编译完成后，应该生成：

```
/opt/share/blesh/out/ble.sh
```

检查：

```
ls -lh /opt/share/blesh/out/ble.sh
```

正常情况下可以看到类似：

```
-rw-r--r-- 1 root root ... /opt/share/blesh/out/ble.sh
```

### 设置公共读取权限

所有服务器用户都需要能够读取 ble.sh：

```
sudo chmod -R a+rX /opt/share/blesh
```

### 创建公共缓存目录

ble.sh 初始化过程中可能需要创建：

```
/opt/share/blesh/out/cache.d
```

由于 `/opt/share/blesh` 通常由 root 所有，普通用户没有写权限。

如果不处理，登录时可能看到：

```
mkdir: cannot create directory '/opt/share/blesh/out/cache.d': Permission denied
ble.sh: failed to initialize $_ble_base_cache.
```

因此创建缓存目录：

```
sudo mkdir -p /opt/share/blesh/out/cache.d
```

设置为类似 `/tmp` 的共享写目录：

```
sudo chmod 1777 /opt/share/blesh/out/cache.d
```

检查：

```
ls -ld /opt/share/blesh/out/cache.d
```

正常应类似：

```
drwxrwxrwt ... /opt/share/blesh/out/cache.d
```

`1777` 中的 sticky bit 可以防止普通用户随意删除其他用户创建的缓存文件。

### 配置每个用户独立的 Bash 历史

创建系统级 Bash 历史配置：

```
sudo tee /etc/profile.d/bash-history.sh > /dev/null <<'EOF'
# Global Bash history settings
# Each user keeps an independent ~/.bash_history

export HISTFILE="$HOME/.bash_history"

export HISTSIZE=100000
export HISTFILESIZE=200000

shopt -s histappend

export HISTCONTROL=ignoreboth:erasedups

if [[ -n "${PROMPT_COMMAND:-}" ]]; then
    PROMPT_COMMAND="history -a; history -n; $PROMPT_COMMAND"
else
    PROMPT_COMMAND="history -a; history -n"
fi
EOF
```

其中：

```
export HISTFILE="$HOME/.bash_history"
```

非常重要。

不同用户会自动对应：

```
/home/wsw2026/.bash_history
/home/user1/.bash_history
/home/user2/.bash_history
```

不会共享历史记录。

检查当前用户：

```
echo "$HISTFILE"
```

例如：

```
/home/wsw2026/.bash_history
```
